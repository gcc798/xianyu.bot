# 分阶段实施计划

## 当前完成：阶段 1 与阶段 2 最小骨架

- 固定 GVA 与旧参考工程基线并完成源码审计。
- 输出复用清单、迁移矩阵、新数据模型、API/菜单规划和风险清单。
- GVA 改用 SQLite；建立 `server/dbdata` 持久化目录，单连接并启用 WAL、busy timeout、外键。
- 注册 Xianyu v2 插件、一级菜单、空白工作台、真实数据库状态 API。
- API 受 JWT + Casbin 保护，菜单和 API 默认仅授予内置管理员角色 `888`。

## 阶段 3：基础业务管理

1. 账号与加密凭证模型，完成 owner 级 CRUD 和权限测试。**已完成。**
2. 商品与商品设置模型，完成真实闲鱼在售商品分页同步。**已完成；授权账号实测同步 8 个商品。**
3. 回复规则、发货规则管理页面与接口。**已完成。**
4. 每个模块完成迁移、Go 测试、Swagger、前端构建和权限验证后再进入下一模块。

退出条件：两个 GVA 用户之间无法读取或修改对方任何闲鱼业务对象；敏感值不出现在 API 列表和日志。

## 阶段 4：通信与凭证

1. 从授权样本建立协议 fixture，先实现纯解析测试。**已完成首个同步消息 fixture，后续随实测样本扩充。**
2. 实现账号级 runtime、有限容量消息队列、心跳、超时和带抖动的指数退避。**已完成，并已接入真实闲鱼 WebSocket 的 Token、注册、同步状态、ACK 与心跳协议。**
3. 实现 HTTP 登录态检查、同账号刷新互斥、凭证版本更新。**已完成，Cookie 合并、加密回写、并发串行与 owner 隔离测试通过。**
4. 实现二维码登录的创建、状态轮询、取消、超时清理和安全验证提示。**已完成，授权账号扫码确认、凭证加密落库与登录态检查已通过。**

当前授权账号已完成扫码确认、登录态检查、WebSocket Token 获取和真实长连接验收。实测发现的空同步批次与无消息控制推送已按协议语义忽略，连接状态会展示最近一次重连错误。消息流现已接入 owner 隔离、`(account, pnmId)` 幂等持久化和分页查询页面。

退出条件：断线/取消/重启测试无 goroutine 泄漏；协议变化返回明确错误，不伪造连接成功。

## 阶段 5：自动回复与 RAG

1. 消息去重与人工接管。**已完成持久化、并发幂等、显式接管/释放和人工回复；人工回复只在服务端确认发送后落库。**
2. 关键词策略与唯一终止条件。**已完成规则优先级、商品开关、同会话延迟合并、持久任务状态、服务端发送回执和结果未知分类。**
3. OpenAI 兼容客户端、Prompt 分区和不可信输入防护。
4. SQLite 元数据、内存精确余弦检索和原子 JSON 快照。

退出条件：重复消息只执行一次；任何检索结果都属于当前 owner 和商品；模型/维度变化触发重建。

## 阶段 6：订单与自动发货

1. 订单/事件与发货任务状态机。**已完成消息幂等入库、卖家接口待发货同步、持久任务与重启扫描。**
2. 文本/卡密真实虚拟发货。**已完成卡密加密、原子预占、结果未知隔离、明确失败重试及远端成功后确认/消耗。**
3. 当前授权账号调用待发货列表接口返回 `PERMISSION_EXCEPTION`，因此真实空列表验收尚不能完成；WebSocket 订单事件入口可用，且不会伪造成功。

## 阶段 7：稳定性和交付

1. 账号连接期间每 30 分钟执行 HTTP Cookie 保活；失效或风控时停止连接和发货扫描。
2. 工作台已提供 owner 隔离统计，业务日志已覆盖登录检查、商品/订单同步、消息和发货结果。
2. 文本规则和卡密资源原子预占。
3. 远端发送、结果核验、未知结果和人工接管。
4. GVA Timer 扫描持久任务并在重启后恢复。

退出条件：两个并发任务不能消费同一卡密；超时未知不会盲目重发；“发送成功”不直接标记交易完成。

## 阶段 7：交付

- 集成与并发测试、SQLite 备份恢复、协议回放、Docker amd64/arm64。
- 分别测量 GVA 空闲、插件空闲、连接、RAG、消息压力和浏览器前后 RSS。
- 按实测结果优化，不预先删除 GVA 可选模块源码。

## 关键决策

| 决策 | 选择 | 放弃方案与原因 |
| --- | --- | --- |
| 插件注册 | GVA v2 registry + `server/plugin/register.go` 空导入 | 修改 GVA 核心路由：升级冲突大 |
| 用户权限 | GVA JWT/Casbin + Service owner 检查 | 复制旧用户表：重复且无法统一审计 |
| SQLite 并发 | 单连接、WAL、短事务 | 引入 Redis/队列：当前规模不需要 |
| 协议迁移 | fixture 驱动适配层 | Java 类逐文件翻译：会固化旧耦合 |
| 发货 | 持久状态机和结果核验 | 以消息发送返回值作为完成：可能重复或漏发 |
| RAG | 精确内存索引 + 原子 JSON 快照 | 专用向量库：部署和内存成本不匹配 |

## 暂不实施

- ProductLayout、独立登录页、双构建、重新上架、外部消息队列和专用向量库。
- 未取得授权协议样本前不实现真实交易、真实发货或验证码自动化；二维码风控只返回闲鱼官方安全验证入口。
- AI 配置与 AI/RAG 能力按当前需求暂不实现，后续仅在用户重新确认后恢复。
