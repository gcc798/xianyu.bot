# 项目范围

## 保留

- 登录、JWT 注销、管理员和普通用户。
- 用户、字典和登录审计。
- 闲鱼账号、扫码登录、商品、消息、回复、订单、发货、续售和业务事件。
- Agent 会话、模型、MCP、Tool、审批、轨迹和资源交付。
- Agent 可查询并经审批操作闲鱼业务，但不管理闲鱼账号或凭据；卡密通过受保护的发货规则导入界面处理。
- Telegram 资源来源和 RustFS 存储。
- PostgreSQL 单库部署。

## 不做

- 动态角色、菜单、API 权限和 Casbin。
- 代码生成、低代码、插件市场和通用工作流设计器。
- 多数据库、Redis、MongoDB 和通用定时任务。
- 与闲鱼或 Agent 无关的演示和通用后台能力。
- 直接公网部署。

## 尚未完成

- 受控模型、Service stub 和浏览器 mock 只验证应用内流程，不构成真实账号或真实交易验收；真实付款、自动发货、平台确认、自动续售和凭据恢复仍需授权账号验收。
- Telegram 会话扫描/退群、成人模式配置和历史文件运维仍由 Python 访问业务表，需按迁移计划继续收归 Go；历史 Telegram 表和对象暂不清理。
