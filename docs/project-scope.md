# 项目范围

## 保留

- 登录、JWT 注销、管理员和普通用户。
- 用户、字典和登录审计。
- 闲鱼账号、扫码登录、商品、消息、回复、订单、发货、续售和业务事件。
- Agent 会话、模型、MCP、Tool、审批、轨迹和资源交付。
- Telegram 资源来源和 RustFS 存储。
- PostgreSQL 单库部署。

## 不做

- 动态角色、菜单、API 权限和 Casbin。
- 代码生成、低代码、插件市场和通用工作流设计器。
- 多数据库、Redis、MongoDB 和通用定时任务。
- 与闲鱼或 Agent 无关的演示和通用后台能力。
- 直接公网部署。

## 尚未完成

- 订单详情等待后端按 ID 查询合同。
- Telegram 管理页面已开发，仍需与运行中的 Telegram 服务联调。
- `web/` 仅保留为上述详情合同的业务参考；React 验收完成后整体删除。
- 真实付款、自动发货、平台确认、自动续售和凭据恢复仍需授权账号验收。
