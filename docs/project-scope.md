# 项目范围

本文件是重构、工作量评估和交付验收的范围基线。能力被验收、删除或明确延期时必须更新。

## 产品目标

部署边界为可信内网；服务不以直接暴露公网为目标，公网接入必须另行补充网关、限流和更强认证。

交付一个可维护系统：

- 保留登录、管理员/普通用户、字典和登录审计后台；
- 支持闲鱼账号、商品、消息、回复、订单、发货和续售；
- 支持可审计的 Agent 会话、MCP 工具、审批、资源和轨迹回放；
- 只维护一个 React 18 + TypeScript 前端；
- 只维护一套由 Goose 管理的 PostgreSQL 表结构历史。

## 保留能力

| 领域 | 能力 |
| --- | --- |
| 身份权限 | 登录、JWT、用户、固定管理员/普通用户边界 |
| 基础数据 | 字典和字典项 |
| 审计 | 登录日志和闲鱼/Agent 领域事件 |
| 闲鱼 | 账号、凭据、商品、消息、回复、订单、发货、续售和业务事件 |
| Agent | 会话、消息、运行、工具、审批、事件、轨迹、模型与 MCP 配置 |
| 资源 | 搜索、候选、异步获取、交付元数据和来源 |
| 数据库 | PostgreSQL 与 Goose |

## 明确删除或不做

- 代码生成和表单生成；
- 插件市场、安装、发布以及闲鱼插件机制；
- 与正常 JWT 登录无关的 API Token 管理；
- 通用参数管理页面；
- 上游 AI 工作流设计器；
- 与闲鱼或 Agent 无关的演示页面；
- 动态角色、菜单、API、按钮、数据权限和 Casbin；
- 验证码、通用操作日志、数据库错误日志和通用文件上传；
- 初始化向导、多数据库、Redis、MongoDB 和通用定时任务；
- Gin-Vue-Admin Swagger 生成物；
- 通用反射校验器、配置热更新和未使用的文件/JSON/MD5 工具；
- 字典导入导出、专用树/路径查询和未被 React 使用的登录日志查询接口；
- React 能力验收后继续并行维护 Vue。

## 证据等级

- **单测**：隔离的包或组件测试。
- **集成**：数据库、HTTP、模拟服务或容器联调。
- **浏览器**：真实渲染并完成登录态流程。
- **真实**：授权外部账号或真实交易。

所需证据等级没有执行时，不得把能力标记为完成。
