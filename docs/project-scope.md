# 项目范围

本文件是重构、工作量评估和交付验收的范围基线。能力被验收、删除或明确延期时必须更新。

## 产品目标

交付一个可维护系统：

- 保留登录、RBAC、字典和审计后台；
- 支持闲鱼账号、商品、消息、回复、订单、发货和续售；
- 支持可审计的 Agent 会话、MCP 工具、审批、资源和轨迹回放；
- 只维护一个 React 18 + TypeScript 前端；
- 只维护一套由 Goose 管理的 PostgreSQL 表结构历史。

## 保留能力

| 领域 | 能力 |
| --- | --- |
| 身份权限 | 登录、JWT、用户、角色、菜单、API 权限 |
| 基础数据 | 字典和字典项 |
| 审计 | 登录、操作和错误日志 |
| 闲鱼 | 账号、凭据、商品、消息、回复、订单、发货、续售和业务事件 |
| Agent | 会话、消息、运行、工具、审批、事件、轨迹、模型与 MCP 配置 |
| 资源 | 搜索、候选、异步获取、交付元数据和来源 |
| 数据库 | PostgreSQL 与 Goose |

## 明确删除或不做

- 代码生成和表单生成；
- 插件市场、安装、发布以及闲鱼插件机制；
- 与正常 JWT 登录无关的 API Token 管理；
- 通用参数管理页面；
- 上游 AI 工作流设计器；
- 与闲鱼或 Agent 无关的演示页面；
- React 能力验收后继续并行维护 Vue。

## 已完成基础

- 闲鱼后端从插件路径迁入 `server/internal/xianyu/`。
- 演示、插件、代码生成、参数和 API Token 管理已移出保留范围。
- 复制的 PostgreSQL 结构已形成 Goose 基线，并接入启动迁移。
- React 已具备登录以及用户、角色、菜单、API、字典和日志基础页面。
- React 已具备 Agent 对话和轨迹页面。
- Vue 已正式冻结。

## 删除 Vue 前必须完成

- 在 React 中补齐角色菜单、API、数据和按钮权限；
- 迁移闲鱼总览、账号、商品、消息、回复规则、订单、发货和业务事件；
- 迁移保留的模型、MCP 和 Agent 配置；
- 确认并迁移需要保留的 Telegram 管理页面；
- 使用非管理员账号验证路由、数据和按钮权限；
- 验证危险操作、加载、空、错误和响应式状态；
- 对每个保留路由执行生产构建和登录态浏览器回归；
- 更新部署，只服务通过验收的 React 应用；
- 单独记录回滚结论后再删除 Vue。

## 仍需真实环境验收

- 真实付款订单事件；
- 自动发货和远端确认；
- 卡密消费状态；
- 真实售出后的自动续售；
- 凭据过期、人机验证和恢复；
- 不同资源渠道的真实获取和最终交付。

## 证据等级

- **单测**：隔离的包或组件测试。
- **集成**：数据库、HTTP、模拟服务或容器联调。
- **浏览器**：真实渲染并完成登录态流程。
- **真实**：授权外部账号或真实交易。

所需证据等级没有执行时，不得把能力标记为完成。
