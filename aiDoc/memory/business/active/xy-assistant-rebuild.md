# 基于 GVA 重构 XyAssistant

## 基本信息

- 提出日期：2026-10-22
- 当前状态：`active`
- 需求类型：业务插件重构
- 优先级：P0
- 需求文件：`aiDoc/memory/business/active/xy-assistant-rebuild.md`

## 用户原始意图摘要

以当前 gin-vue-admin 为主体，将旧 Java XyAssistant 的有效业务能力按 GVA 原生插件方式重新设计并逐阶段实现。

## 影响范围

- 后端：SQLite、Xy 插件、账号/商品/消息/回复/RAG/订单/发货等后续模块。
- 前端：`web/src/plugin/xy/` 下的 GVA 原生业务页面。
- 文档：架构、迁移矩阵、数据模型、计划、业务流程、测试与部署文档。
- 插件 / 模块：`server/plugin/xy/`、`web/src/plugin/xy/`。

## 已确认约束

- 不机械迁移 Java Controller、Service、Entity 或旧页面。
- 复用 GVA 用户、JWT、Casbin、菜单、日志、配置、响应和前端基础设施。
- 单体、SQLite、低内存；不默认引入 Redis、消息队列或向量数据库。
- 对象级权限以 GVA 用户 ID 为 owner；敏感凭证不得明文日志或响应。
- 未授权协议行为只做风险说明，不绕过验证码或风控。
